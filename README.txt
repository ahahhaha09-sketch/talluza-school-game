مهمة إنقاذ الطائر — ملفات تطبيق ويب تقدّمي (PWA)
====================================================

الملفات:
- index.html: اللعبة
- manifest.json: بيانات التطبيق وأيقونته
- sw.js: حفظ ملفات اللعبة للتشغيل دون إنترنت بعد أول زيارة
- icon-192.png و icon-512.png: أيقونة التطبيق

طريقة النشر المجاني باستخدام GitHub Pages:
1. سجّل الدخول إلى https://github.com من متصفحك.
2. اضغط + ثم New repository.
3. سمّ المستودع bird-rescue-game واجعله Public، ثم Create repository.
4. ارفع الملفات الخمسة الموجودة في هذه الحزمة إلى جذر المستودع (Add file > Upload files)، ثم Commit changes.
5. افتح Settings > Pages.
6. في Build and deployment اختر Deploy from a branch.
7. اختر Branch: main و Folder: /(root)، ثم Save.
8. انتظر حتى يظهر رابط الموقع في صفحة Pages وافتحه. يجب أن يكون الرابط HTTPS.
9. اترك اللعبة تفتح مرة وهي متصلة بالإنترنت حتى تُحفظ ملفاتها.
10. على iPhone/iPad: افتح الرابط في Safari > مشاركة > Add to Home Screen (إضافة إلى الشاشة الرئيسية) > Add.
11. على Android: افتح الرابط في Chrome > قائمة ⋮ > Install app أو Add to Home screen.
12. جرّب إيقاف الإنترنت وفتح التطبيق من أيقونته.

ملاحظات:
- لا يمكن تثبيت PWA وتشغيل Service Worker عبر فتح ملف HTML محلي مباشرة؛ يجب نشره عبر HTTPS أولًا.
- التشغيل دون إنترنت يبدأ بعد نجاح تحميل اللعبة وملفاتها مرة واحدة.
- عند تحديث اللعبة مستقبلًا، غيّر CACHE_NAME في sw.js من bird-rescue-v1 إلى bird-rescue-v2 ليتجدد التخزين.
- هذه نسخة تطبيق ويب وليست تطبيقًا منشورًا في App Store أو Google Play.
- راجع الأسئلة والنصوص قبل استخدامها في الصف؛ بعض أمثلة اللعبة تحتاج مطابقة دقيقة مع نص الكتاب.
